How to Give File Context and Browser Version to AI

How to mention related files and browser version when asking AI for help in Clincoo so the solution fits.

Without the file name and browser version, AI gives a generic solution that does not fit Clincoo.

Name the file and browser

In editor.clincoo.buzz write the file name, the suspected line, and the browser version used (e.g. Chrome 120). Note if the error is mobile-only.

Test in the same environment

On app.clincoo.buzz repeat in the same browser. Record on blog.clincoo.buzz.
