How to State Constraints Before Asking AI for Code

How to write constraints (do not touch other files, CSS only, etc.) so AI answers in Clincoo stay focused.

Without constraints, AI often changes many files at once and becomes hard to review.

Write constraints first

In editor.clincoo.buzz start with: only change styles.css, do not touch HTML, do not add libraries. Name one goal.

Reject if it violates

On app.clincoo.buzz if the answer touches other files, ask for a revision. Record constraints that worked on blog.clincoo.buzz.
