Cara Sebutkan Batasan Sebelum Minta Kode ke AI

Tata cara menulis batasan (jangan ubah file lain, hanya CSS, dll) agar jawaban AI di Clincoo tetap fokus.

Tanpa batasan, AI sering mengubah banyak file sekaligus dan sulit ditinjau.

Tulis batasan di awal

Di editor.clincoo.buzz mulai dengan: hanya ubah file styles.css, jangan sentuh HTML, jangan tambah library. Sebut satu tujuan.

Tolak jika melanggar

Di app.clincoo.buzz jika jawaban menyentuh file lain, minta revisi. Catat batasan yang berhasil di blog.clincoo.buzz.
