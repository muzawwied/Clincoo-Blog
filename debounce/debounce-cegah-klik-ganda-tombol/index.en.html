How to Debounce Button Clicks to Prevent Double Submit in Clincoo

How to prevent double-clicks on a submit button with debounce or temporary disable in Clincoo.

A double-click on a submit button can send the form twice.

Disable the button during processing

In editor.clincoo.buzz on click, set button.disabled = true, then re-enable after the fetch finishes. Or debounce for 300 ms.

Test rapid clicks

On app.clincoo.buzz click twice quickly. Only one request should leave. Note it on blog.clincoo.buzz.
