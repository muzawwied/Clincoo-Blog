How to Use Leading Debounce on a Submit Button

How to use leading-edge debounce so the first click runs immediately and subsequent clicks are ignored briefly.

Trailing debounce waits until the user stops. For a submit button the first click must send immediately; extra clicks should be ignored.

Leading edge and a flag

In editor.clincoo.buzz write a debounce that runs the callback on the first click, then sets a timer to ignore further clicks until the delay ends. Use an isPending flag.

Test rapid double clicks

On app.clincoo.buzz click the button twice within 300 ms. Only one request should go out. Record it on blog.clincoo.buzz.
