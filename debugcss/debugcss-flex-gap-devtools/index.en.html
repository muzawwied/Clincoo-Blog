How to Debug Incorrect Flexbox Gap

How to inspect Flexbox gap and alignment in Clincoo using DevTools.

Wrong Flexbox gap makes item spacing uneven. DevTools helps see the computed gap.

View computed gap

In editor.clincoo.buzz select the flex container, open Computed, and look for gap. Compare with the expected value.

Test with force state

On app.clincoo.buzz temporarily change gap in Styles. Note the correct value on blog.clincoo.buzz.
