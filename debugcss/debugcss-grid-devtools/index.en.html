How to Debug CSS Grid in DevTools

How to use the Grid overlay in Chrome DevTools to inspect tracks and areas in Clincoo.

A grid that does not match is often due to wrong tracks or areas. DevTools can show an overlay.

Enable the Grid overlay

In editor.clincoo.buzz select the grid element in Elements, then in Styles click the grid badge to show track lines.

Check areas and gap

On app.clincoo.buzz see if items sit in the correct areas. Note wrong tracks on blog.clincoo.buzz.
