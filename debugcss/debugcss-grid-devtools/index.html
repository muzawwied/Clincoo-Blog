Cara Debug CSS Grid di DevTools

Tata cara memakai overlay Grid di Chrome DevTools untuk memeriksa track dan area di Clincoo.

Grid yang tidak sesuai sering karena track atau area salah. DevTools bisa menampilkan overlay.

Aktifkan overlay Grid

Di editor.clincoo.buzz pilih elemen grid di Elements, lalu di panel Styles klik badge grid untuk menampilkan garis track.

Periksa area dan gap

Di app.clincoo.buzz lihat apakah item duduk di area yang benar. Catat track yang salah di blog.clincoo.buzz.
