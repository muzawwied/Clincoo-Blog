How to Debug a Transition That Does Not Run

How to find why a Clincoo CSS transition does not animate.

A still transition is often because the changed property is not in the list or the duration is 0.

Check the transition property

In editor.clincoo.buzz look in Styles for transition-property and duration. Make sure the changed property is listed.

Test in the Animations panel

On app.clincoo.buzz open the Animations panel and trigger the change. Note the cause on blog.clincoo.buzz.
