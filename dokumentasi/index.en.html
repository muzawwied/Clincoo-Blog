QRIS Payment Gateway API Reference (ClincooPay)

ClincooPay is the built-in Clincoo payment gateway: buyers pay with QRIS, the balance lands in your project dashboard, and you can withdraw it anytime. This is the official API reference for sites deployed from app.clincoo.buzz .

Clincoo AI Assistant

The AI assistant lives inside every Clincoo project and understands your workspace. It answers questions, writes and edits code, manages files, and even runs commands — you just ask in everyday language.

How to Set a Heading Hierarchy

A heading is the page outline, not a way to make text bigger. In the HTML file of an editor.clincoo.buzz project, use one h1 for the page title, h2 for sections, and h3 for subsections.

How to Set Project Environment Variables

Environment variables store a secret outside the files visitors download. Static HTML and JS stay public after deploy, so a key pasted there is effectively shared.

How to Read a Failed Deploy Log

A failed deploy usually stops on one line that names a file or a command. Read that line in the log before pressing deploy again in editor.clincoo.buzz .

How to Build a Two-Column Grid Layout

Grid fits side-by-side cards that should line up. In editor.clincoo.buzz wrap the items in one element, then set the columns in CSS, not with a table.

How to Optimize Images Before Deploy

A full camera photo is often larger than the HTML and CSS combined. Shrink it before deploy so the preview and the live site are both fast.

How to Use the Terminal in the Clincoo Editor

The terminal in editor.clincoo.buzz runs Linux commands in the project session. The session lasts a few minutes between commands, and tools installed in that session disappear when it ends.

How to Center an Element with Flexbox

Centering that drifts when the width changes is usually still using a fixed margin. Flexbox calculates the leftover space. Edit in editor.clincoo.buzz and check the live preview.
