How to Check response.ok Before Parsing JSON in Clincoo Fetch

How to always check response.ok or status before calling response.json() so HTTP errors are not missed in Clincoo.

response.json() succeeds even on 404 or 500, hiding the error.

Check ok first

In editor.clincoo.buzz write if (!response.ok) throw new Error(response.status); then await response.json().

Show a clear message

On app.clincoo.buzz catch the error and show the status. Note it on blog.clincoo.buzz.
