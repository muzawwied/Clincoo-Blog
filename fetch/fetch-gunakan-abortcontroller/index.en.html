How to Cancel a Fetch Request with AbortController in Clincoo

How to use AbortController so a fetch request can be canceled when the user navigates or the input changes in Clincoo.

An uncanceled fetch can keep running and overwrite newer results.

Create the signal

In editor.clincoo.buzz const controller = new AbortController(); fetch(url, { signal: controller.signal }). When needed, controller.abort().

Catch AbortError

On app.clincoo.buzz catch error.name === 'AbortError' and ignore it. Note it on blog.clincoo.buzz.
