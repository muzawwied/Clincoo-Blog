Cara Batalkan Permintaan Fetch dengan AbortController di Clincoo

Tata cara memakai AbortController agar permintaan fetch bisa dibatalkan saat pengguna pindah halaman atau input berubah di Clincoo.

Permintaan fetch yang tidak dibatalkan bisa terus jalan dan menimpa hasil baru.

Buat signal

Di editor.clincoo.buzz const controller = new AbortController(); fetch(url, { signal: controller.signal }). Saat perlu batal, controller.abort().

Tangkap AbortError

Di app.clincoo.buzz catch error.name === 'AbortError' dan abaikan. Catat di blog.clincoo.buzz.
