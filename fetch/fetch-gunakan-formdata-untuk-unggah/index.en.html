How to Use FormData to Upload Files with Fetch in Clincoo

How to send files and form fields with FormData via fetch without manually setting Content-Type.

FormData sets the boundary itself; do not set Content-Type manually.

Create FormData

In editor.clincoo.buzz new FormData(); append('file', fileInput.files[0]); then fetch(url, { method: 'POST', body: formData }).

Do not set Content-Type

On app.clincoo.buzz let the browser set it. Note it on blog.clincoo.buzz.
