How to Send Custom Headers with Fetch in Clincoo

How to add headers such as Content-Type or Authorization to Clincoo fetch requests.

Default headers are not enough for APIs that need a token or JSON.

Headers object

In editor.clincoo.buzz add headers: { 'Content-Type': 'application/json', 'Authorization': 'Bearer ...' } to the fetch options.

Test in the Network tab

On app.clincoo.buzz open DevTools Network and confirm the headers were sent. Note it on blog.clincoo.buzz.
