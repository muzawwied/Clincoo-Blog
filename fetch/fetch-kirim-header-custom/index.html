Cara Kirim Header Custom dengan Fetch di Clincoo

Tata cara menambahkan header seperti Content-Type atau Authorization pada permintaan fetch Clincoo.

Header default tidak cukup untuk API yang butuh token atau JSON.

Objek headers

Di editor.clincoo.buzz tambahkan headers: { 'Content-Type': 'application/json', 'Authorization': 'Bearer ...' } pada opsi fetch.

Uji di Network tab

Di app.clincoo.buzz buka DevTools Network, pastikan header terkirim. Catat di blog.clincoo.buzz.
