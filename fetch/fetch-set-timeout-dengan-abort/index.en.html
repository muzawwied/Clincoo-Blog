How to Set a Timeout on Fetch Using AbortController in Clincoo

How to limit the wait time for a fetch so it does not hang forever in Clincoo.

Fetch has no built-in timeout. Use AbortController + setTimeout.

Abort after 8 seconds

In editor.clincoo.buzz const controller = new AbortController(); setTimeout(() => controller.abort(), 8000); fetch(url, { signal: controller.signal }).

Show a timeout message

On app.clincoo.buzz if AbortError after the timeout, show 'Request took too long'. Note it on blog.clincoo.buzz.
