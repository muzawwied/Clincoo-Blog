Cara Set Timeout pada Fetch Menggunakan AbortController di Clincoo

Tata cara membatasi waktu tunggu fetch agar tidak menggantung selamanya di Clincoo.

Fetch tidak punya timeout bawaan. Gunakan AbortController + setTimeout.

Abort setelah 8 detik

Di editor.clincoo.buzz const controller = new AbortController(); setTimeout(() => controller.abort(), 8000); fetch(url, { signal: controller.signal }).

Tampilkan pesan timeout

Di app.clincoo.buzz jika AbortError setelah timeout, tampilkan 'Permintaan terlalu lama'. Catat di blog.clincoo.buzz.
