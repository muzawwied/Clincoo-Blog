How to Handle Network Errors on Fetch in Clincoo

How to distinguish network errors from HTTP errors and show helpful messages to Clincoo users.

Fetch only rejects on network failure, not on bad status.

Catch in try/catch

In editor.clincoo.buzz wrap fetch in try. TypeError or Failed to fetch means network.

Different messages

On app.clincoo.buzz show 'Check connection' for network, status for HTTP. Note it on blog.clincoo.buzz.
