Cara Tangani Network Error pada Fetch di Clincoo

Tata cara membedakan error jaringan dari error HTTP dan menampilkan pesan yang membantu pengguna Clincoo.

Fetch menolak hanya saat jaringan putus, bukan saat status buruk.

Tangkap di try catch

Di editor.clincoo.buzz bungkus fetch dalam try. Jika TypeError atau Failed to fetch, itu jaringan.

Pesan berbeda

Di app.clincoo.buzz tampilkan 'Periksa koneksi' untuk network, status untuk HTTP. Catat di blog.clincoo.buzz.
