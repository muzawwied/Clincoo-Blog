How to Avoid Synchronous Layout in Event Handlers

How to avoid reading layout (offsetWidth, getBoundingClientRect) inside click or input handlers that hurt INP.

Reading offsetWidth inside a click handler forces the browser to calculate layout before continuing, adding input delay.

Read once outside the handler

In editor.clincoo.buzz measure size on resize or when the panel opens, store it in a variable. In the handler only use the already measured value.

Test in the Performance panel

On app.clincoo.buzz record the interaction. There should be no forced reflow inside the handler. Record it on blog.clincoo.buzz.
