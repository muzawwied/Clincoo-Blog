Cara Hindari Synchronous Layout di Event Handler

Tata cara menghindari baca layout (offsetWidth, getBoundingClientRect) di dalam handler click atau input yang membuat INP buruk.

Membaca offsetWidth di dalam click handler memaksa browser menghitung layout sebelum melanjutkan, menambah waktu input.

Baca sekali di luar handler

Di editor.clincoo.buzz ukur ukuran saat resize atau saat buka panel, simpan di variabel. Di handler hanya gunakan nilai yang sudah diukur.

Uji di Performance panel

Di app.clincoo.buzz rekam interaksi. Tidak boleh ada forced reflow di handler. Catat di blog.clincoo.buzz.
