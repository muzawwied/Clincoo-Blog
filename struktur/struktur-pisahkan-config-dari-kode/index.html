Cara Pisahkan Konfigurasi dari Kode di Clincoo

Tata cara memisahkan file konfigurasi agar perubahan lingkungan tidak menyentuh kode sumber di proyek Clincoo.

Mengubah nilai di tengah kode sumber membuat deploy berbeda lingkungan menjadi rawan error.

Pindahkan ke file config

Di editor.clincoo.buzz buat config.js atau .env yang di-import. Jangan hardcode URL API atau kunci di komponen.

Uji di preview

Di app.clincoo.buzz ganti nilai config dan pastikan perilaku berubah tanpa edit kode. Catat di blog.clincoo.buzz.
