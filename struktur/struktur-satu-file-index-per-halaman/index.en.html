How to Create One index.html per Page

How to structure Clincoo folders with one index.html in each page folder for simple routing.

One large file with many pages makes navigation and caching harder. One folder per page is clearer.

Folder named after the slug, index.html inside

In editor.clincoo.buzz create a /tentang/ folder containing index.html. The URL becomes /tentang/ without .html. Do not put everything in the root.

Test relative links

On app.clincoo.buzz make sure links between pages still work after moving folders. Record the structure on blog.clincoo.buzz.
