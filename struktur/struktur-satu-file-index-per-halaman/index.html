Cara Buat Satu index.html per Halaman

Tata cara menstruktur folder Clincoo dengan satu index.html di setiap folder halaman agar routing sederhana.

Satu file besar dengan banyak halaman mempersulit navigasi dan cache. Folder per halaman lebih jelas.

Folder nama slug, index.html di dalamnya

Di editor.clincoo.buzz buat folder /tentang/ berisi index.html. URL menjadi /tentang/ tanpa .html. Jangan taruh semua di root.

Uji tautan relatif

Di app.clincoo.buzz pastikan tautan antar halaman tetap benar setelah pindah folder. Catat struktur di blog.clincoo.buzz.
