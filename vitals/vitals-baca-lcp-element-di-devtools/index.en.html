How to Read the LCP Element in DevTools Performance

How to find the element that becomes Largest Contentful Paint in Clincoo.

Slow LCP is often caused by a large image or text element that loads late.

Record Performance and find LCP

In editor.clincoo.buzz open DevTools Performance, record a page reload. In the Experience or Timings panel, click the LCP marker to see the measured element.

Optimize that element

In app.clincoo.buzz ensure the LCP image has width/height and fetchpriority high. Record the element on blog.clincoo.buzz.
