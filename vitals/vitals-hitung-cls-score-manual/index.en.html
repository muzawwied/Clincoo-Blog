How to Calculate CLS Score Manually in the Console

How to use PerformanceObserver for layout-shift and compute the CLS score in Clincoo.

Lighthouse gives a CLS score, but the console lets you see every shift in real time.

Attach a layout-shift observer

In editor.clincoo.buzz create a PerformanceObserver with type layout-shift. Accumulate the value from entries where hadRecentInput is false. Log the total CLS.

Compare with Lighthouse

In app.clincoo.buzz record normal user interactions. The score should match the report. Save the log on blog.clincoo.buzz.
