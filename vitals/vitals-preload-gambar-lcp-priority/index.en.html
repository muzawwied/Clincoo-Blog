How to Preload the LCP Image with Priority Hint

How to prioritize loading the LCP image in Clincoo with preload and fetchpriority.

An LCP image that is not prioritized waits for other resources to finish loading.

Add a preload link

In editor.clincoo.buzz add in the head for the hero image. On the img tag also set fetchpriority="high".

Verify the waterfall

In app.clincoo.buzz open the Network tab and see whether the LCP image starts earlier. Save the screenshot on blog.clincoo.buzz.
