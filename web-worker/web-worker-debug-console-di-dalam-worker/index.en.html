How to Debug a Web Worker with Console Inside the Worker in Clincoo

How to use console.log inside a Web Worker and view it in DevTools for debugging Clincoo.

Console in a worker appears in the same tab but is separate.

Log inside the worker

In editor.clincoo.buzz inside worker.js write console.log('worker start', data). Open DevTools Console and filter or check the worker context.

Use the debugger

On app.clincoo.buzz set a breakpoint in Sources on the worker file. Note it on blog.clincoo.buzz.
