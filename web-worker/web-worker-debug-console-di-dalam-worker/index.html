Cara Debug Web Worker dengan Console di Dalam Worker Clincoo

Tata cara menggunakan console.log di dalam Web Worker dan melihatnya di DevTools untuk debug Clincoo.

Console di worker muncul di tab yang sama, tapi terpisah.

Log di worker

Di editor.clincoo.buzz di dalam worker.js tulis console.log('worker start', data). Buka DevTools Console, filter atau lihat konteks worker.

Gunakan debugger

Di app.clincoo.buzz set breakpoint di Sources pada file worker. Catat di blog.clincoo.buzz.
