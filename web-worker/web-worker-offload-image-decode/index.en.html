How to Offload Image Decoding to a Web Worker in Clincoo

How to move heavy image decoding to a Web Worker so the Clincoo UI does not freeze.

Decoding a large image on the main thread causes jank. Move it to a worker.

Send the blob to the worker

In editor.clincoo.buzz worker.postMessage({ blob }); in the worker use createImageBitmap or OffscreenCanvas if available.

Return the result

On app.clincoo.buzz receive the ImageBitmap and draw it to canvas. The UI stays responsive. Note it on blog.clincoo.buzz.
