Cara Offload Decode Gambar ke Web Worker di Clincoo

Tata cara memindahkan decode gambar berat ke Web Worker agar UI Clincoo tidak freeze.

Decode gambar besar di thread utama membuat jank. Pindahkan ke worker.

Kirim blob ke worker

Di editor.clincoo.buzz worker.postMessage({ blob }); di worker gunakan createImageBitmap atau OffscreenCanvas jika tersedia.

Kembalikan hasil

Di app.clincoo.buzz terima ImageBitmap dan gambar ke canvas. UI tetap responsif. Catat di blog.clincoo.buzz.
